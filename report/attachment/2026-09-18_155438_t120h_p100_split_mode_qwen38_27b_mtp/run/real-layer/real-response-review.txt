# 技術文書レビュー：3観点の検討フレームワーク

ご提示いただいた観点順に、具体例を交えてレビューの進め方を示します。実在の文書が添付されていないため、**「新規触媒Xが反応収率を従来触媒Aに対して30%向上させた」** という仮説的な技術報告を想定例として用います。

---

## 1. 主張の根拠が測定に基づいているか

### 確認すべきこと

「30%向上」という数値が、**誰が・どの機器で・何度・どのような条件下で**計測したのか、その測定チェーンが追跡可能か。

### 具体的な反例

> **「収率30%向上」という主張が、実はGC（ガスクロマトグラフ）の検量線が1年点検されておらず、ピーク面積の積分範囲が手動で毎回異なっていたケース。**

- 従来触媒Aの測定：2023年、検量線校正済み、自動積分
- 触媒Xの測定：2024年、検量線未校正（ドリフト＋8%）、手動積分（ピーク裾を0.5分長く取った）
- 結果：「真の差22%」が「見かけの差30%」として報告される

### レビュー時のチェックリスト

| 項目 | 確認ポイント |
|------|-------------|
| 測定機器の校正記録 | 有効期限内か、校正証明書添付か |
| 反復回数 | n≥3か、標準偏差が報告されているか |
| 盲検性 | 測定者が「どちらが新触媒か」を知っていたか |
| 検出限界 | 微量副生成物がLOD（検出限界）以下で無視されていないか |
| 単位と換算 | 収率＝(生成物モル)/(反応物投入モル)の定義が両触媒で一致するか |

---

## 2. 見落とされている交絡因子はないか

### 確認すべきこと

「触媒X vs 触媒A」の比較において、**触媒以外の条件が同期していない**要素がないか。

### 具体的な反例（3つ）

**反例A：反応温度の制御差**
- 触媒Aの試験：500 Wのヒータ、制御精度±2 °C
- 触媒Xの試験：新設した800 Wヒータ、制御精度±5 °C（ベンチの配線が長いため）
- 触媒Xは高温度寄りに反応 → 温度効果が「触媒効果」に混入

**反例B：触媒の粒径・比表面積の非同期**
- 触媒A：粒径 2–4 mm（従来ロット）
- 触媒X：粒径 0.5–1 mm（新ロット、粉砕工程が異なる）
- 気-固反応では粒径が収率に直結 → 「触媒組成の差」ではなく「粒径の差」が主因
