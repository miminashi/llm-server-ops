## 観点1：主張の根拠が測定に基づいているか

### 問題の核心

技術文書で最も多い致命傷は、「測定したことを装いながら、実は推論・計算・体感に立脚している」構造です。レビューの第一関門は、**各定量主張に対して、いつ・どこで・何回・何の装置で測ったか**が追跡可能かを確認することです。

### 反例A：計算機科学（アルゴリズム比較）

> **文書の主張：** 「提案アルゴリズムは既存手法比3.2倍高速である（Table 2）」

> **Table 2の実体：** 各行に「実行時間 (ms)」の列があり、数字は書かれている。しかし方法論セクションを読むと、

- 測定は**1回だけ**、**1台のワークステーション**（Xeon Gold 6338, 32GB RAM）上で行われている
- 入力データは**1パターンのみ**（n = 10⁶ の均一ランダム）
- OSのバッファリング、ページング、他プロセスの影響が制御されていない
- 「3.2倍」は単一サンプルの比であり、中央値・分散・信頼区間が一切ない

> **レビューコメント：** 「3.2倍」という主張は測定値の*記述*ではあるが、*根拠としての測定*ではない。1サンプルの比はノイズと区別不能である。少なくともn≥10の反復、異なる入力分布（偏り・クラスタリング・境界値）、OSレベルの制御（`perf_event`、CPU pinning）がなければ、この数字は再現不能であり、主張の根拠として成立しない。

### 反例B：材料工学（強度改善）

> **文書の主張：** 「ナノ粒子添加により引張強度が15%向上した（Fig. 4）」

> **Fig. 4の実体：** 棒グラフ2本（対照群 vs 添加群）。しかし、

- 各群の試料数は**n = 2**
- 破断位置のSEM写真が1枚のみ添付
- 試験機の荷重セル較正記録、試験速度（1 mm/min vs 5 mm/minで結果が変わる）、温度制御の記述がない
- 「15%」は2本の棒の平均比であり、2点の比は統計的に意味を持たない

> **レビューコメント：** n = 2の「平均」は測定値の列挙であり、分布の推定ではない。引張試験は試料の微小欠陥に極めて敏感であり、2点では「添加効果」か「たまたま欠陥の少ない2本が引いたか」を区別できない。最低でもn ≥ 10、Weibull解析、試験条件の完全記述がなければ、15%という数字は偶然の範囲に収まる。
